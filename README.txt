L’UNION — GÉNÉRATEUR DE BESTIAIRE V2 (PWA)

Mise à jour GitHub Pages :
1. Ouvrez le dépôt GitHub > Code.
2. Remplacez index.html, manifest.webmanifest et service-worker.js à la racine.
3. Ajoutez les images du dossier icons/ dans le dossier icons/ du dépôt.
4. Validez avec Commit changes.
5. Attendez le déploiement dans Actions puis rechargez le site.
6. Sur Android, ouvrez le site avec Chrome > menu ⋮ > Ajouter à l’écran d’accueil / Installer l’application.

Ne téléversez pas le ZIP : téléversez les fichiers qu’il contient.
Les sauvegardes existantes sont conservées dans le même navigateur sur la même origine (nom de domaine et chemin).
Le stockage local ne se synchronise pas entre appareils.
L’installation PWA dépend du navigateur et de ses critères ; GitHub Pages doit être actif sur HTTPS.
